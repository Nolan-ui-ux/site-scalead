# Scalead - Site Web Complet Next.js

Site web complet pour Scalead, agence de développement commercial B2B en France.

## Stack Technique

- Next.js 14 (App Router) + React 18 + TypeScript
- Tailwind CSS + Framer Motion
- SEO optimisé (Sitemap, Schema.org, Meta tags)

## Installation

```bash
npm install
npm run dev
```

## Structure

- `/app` - Pages Next.js
- `/components` - Composants réutilisables
- `/public` - Fichiers statiques

## Pages Créées

✅ Page d'accueil
✅ 5 pages piliers SEO (développement commercial, cold email, LinkedIn, multicanal, IA)
